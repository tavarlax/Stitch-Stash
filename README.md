# Stitch Stash

A cross-stitch app: track your DMC floss, turn pictures into patterns, and see what to buy.
It runs entirely in your browser — your data is saved on your device, with optional sync to a private GitHub repository (see Settings in the app).

Files:
- `index.html` — the app
- `manifest.webmanifest`, `icons/` — let your phone install it with its own icon
- `sw.js` — lets it open offline
