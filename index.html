Sync with GitHub

Optional. Keeps a copy of your floss and patterns in a private GitHub repository, so they’re backed up and the same on every device you use.

How to set it up (about 5 minutes)
  1. On GitHub, create a new repository called stitchstash-data. Set it to Private.
  2. Go to Settings → Developer settings → Personal access tokens → Fine-grained tokens, and tap Generate new token.
  3. Give it a name, choose an expiration (e.g. 1 year), and under Repository access pick Only select repositories → stitchstash-data.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Tap Generate token, copy it, and paste it below.

Do the same Connect step on each device you use, with the same repository and token.

Syncing with .

Changes sync a few seconds after you make them, when you open the app, and every minute while it’s open. Offline changes sync when you’re back online.

Backup

Importing merges the backup with what’s already here — nothing is deleted. Backups include your floss lists for imported PDF patterns but not the PDF files themselves; keep your originals.
